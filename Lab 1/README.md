# Лабораторная работа №1

## Тема

**Настройка среды разработки. Первая программа**

## Цель работы

Изучить среду разработки, научиться создавать, компилировать и запускать программу на языке C++.

## Выполненная работа

В ходе лабораторной работы:

- настроена среда разработки;
- создана первая программа на C++;
- изучен вывод данных с помощью `cout`;
- изучен ввод данных с помощью `cin`;
- реализована проверка введённых данных;
- выполнены задания базового, среднего и повышенного уровня.

## Структура

- `report.pdf` — отчёт по лабораторной работе;
- `src/Basic.cpp` — задания базового уровня;
- `src/Medium.cpp` — задания среднего уровня;
- `src/Advanced.cpp` — задания повышенного уровня.
